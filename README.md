# gronare plugins

A Claude Code plugin marketplace.

```bash
claude plugin marketplace add https://github.com/gronare/claude-plugins
```

| Plugin | What it is | Install |
|---|---|---|
| `vault` | [mindin](https://github.com/gronare/mindin): your Obsidian vault, in a local folder, an S3 bucket or on a vault server, as Claude's persistent memory, with session-start context, a repo log and lint. | `claude plugin install vault@gronare` |

The plugin's files, settings and updates are described in [mindin's Claude Code guide](https://github.com/gronare/mindin/blob/main/docs/how-to/claude-code.md).
